# Branches · rename extension

Mode: Operate. Repository writers manage branch names; admins manage names of
default/protected branches. Existing branch browsing and creation stay intact.
The user selected the Harness Paper/Graphite pair and compact top navigation.
This is a local extension, with no new visual identity or generated imagery.

## Direction contract

THESIS: Rename is a deliberate inline branch action with a preview of actual
effects. Branch content and protection stay legible throughout the task.

OWN-WORLD: Inherit the shared Harness surface, ink, line and amber tokens,
Geist type, compact controls and existing branch rows. No new color or shadow.

STORY: Choose Rename beside one branch, enter its new name, inspect the current
default/PR effects, then confirm. Errors retain the entered name. A changed
repository requires a fresh preview; uncertain writes require inspection.

FIRST VIEWPORT: Keep the existing heading, search and branch list. Add a quiet
Rename action at each eligible row's trailing edge. The form opens within that
row and expands to full width; labels and controls stack on narrow screens.

FORM: Existing branch-list extension; code-led. No concept roll is applicable
to this narrowly scoped action. Preserve both light and dark theme behavior.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
